# Demo

Isi folder ini sebelum submit (sesuai langkah 9 brief):

- `list.png` — daftar token menampilkan FRESH, EARLY, HALF, TAXED, GRAD
- `buy.png` — form beli dengan estimasi + slippage
- `tx-success.png` — pesan sukses + jumlah token + link explorer `https://explorer.testnet.chain.robinhood.com/tx/<hash>`

Alternatif: `demo.mp4` (video singkat) boleh menggantikan/menambah screenshot.

Cara ambil cepat:
1. `npm run dev` → buka http://localhost:3000
2. Connect MetaMask (Robinhood Chain Testnet)
3. Screenshot daftar → beli token kecil (mis. FRESH 0.001 ETH) → screenshot sukses
